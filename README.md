# ตำหนักผู่โถวเจ้าแม่กวนอิม · 普陀觀音堂

เว็บไซต์ตำหนักผู่โถวเจ้าแม่กวนอิม ถนนพุทธมณฑลสาย ๒
เป้าหมายของเว็บนี้คือเป็นแหล่งข้อมูลที่ถูกต้องและครบที่สุดเรื่อง
“เจ้าแม่กวนอิม ๓๓ ปาง” ในภาษาไทย โดยผูกความรู้นั้นเข้ากับองค์จริงที่ประดิษฐานอยู่ในตำหนัก

**หมุดหมายที่ทุกอย่างล้ออยู่: พิธีเปิดตำหนัก ๒๕ ตุลาคม ๒๕๖๙**

---

## เริ่มใช้งาน

```bash
npm install
npm run dev          # เปิด http://localhost:4321
npm run build        # สร้างเว็บลง dist/
```

ต้องใช้ Node 22 ขึ้นไป

## คำสั่งทั้งหมด

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | เซิร์ฟเวอร์สำหรับพัฒนา |
| `npm run build` | สร้างเว็บ HTML คงที่ลง `dist/` |
| `npm run preview` | ดูผลลัพธ์ที่สร้างแล้ว |
| `npm run images` | `photos-src/` → WebP ๓ ขนาด ลง `public/images/` |
| `npm run og` | สร้างภาพพรีวิวตอนแชร์ ๓๔ ไฟล์ ลง `public/og/` |
| `npm run qr` | แผ่นพิมพ์ป้าย QR ๓๕ ชิ้น ลง `dist-qr/qr-sheet.html` |
| `npm run lunar -- 2027` | ร่างวันสำคัญจันทรคติของปีนั้น |
| `npm run import:sheet -- <url>` | Google Sheet → ไฟล์ข้อมูล ๓๓ ปาง |
| `npm run import:book` | ต้นฉบับหนังสือ → หน้าปางย่อ + บทเต็ม ๓๓ บท |

## ระบบภาพ

**สัดส่วนตามอาคารจริง** ผนังปูนขาวเป็นส่วนใหญ่ แดงกับทองอยู่เฉพาะที่ป้ายและบานประตู
เว็บจึงแบ่งเป็นสองโซน — **โซนมืด** (หัวเว็บ แถบเมนู หัวเรื่องของหน้า ท้ายเว็บ)
เป็นรักแดงเข้มตัดทองคำเปลว และ **โซนสว่าง** สำหรับเนื้อหาที่ต้องอ่านยาว
เพราะผู้ใช้หลักเป็นผู้สูงอายุอ่านบนมือถือกลางแดด พื้นมืดทั้งเว็บจะอ่านไม่ไหว

โซนมืดทำเป็น **ขอบเขตของโทเคน** (`.zone-dark` ใน `global.css`) ไม่ใช่คลาสของแต่ละชิ้น
คอมโพเนนต์ที่วางข้างในจึงเปลี่ยนสีตามเองโดยไม่ต้องแก้

**ทองสี่บทบาท** ทองที่อ่านได้บนพื้นสว่าง (`--gold` #8E6A16) กับบนพื้นมืด (#E8C86A)
คนละสีกัน ใช้โทเคนเดียวไม่ได้ อีกสองบทบาทคือทองทึบสำหรับไอคอนและปุ่ม (`--gold-bright`)
กับเส้นขลิบ (`--gold-line`) ซึ่ง**ห้ามใช้เป็นสีตัวอักษร** คอนทราสต์ไม่ผ่าน
ส่วน `--gold-metal` เป็นไล่เฉดเจ็ดจุดสีสำหรับตัวอักษรใหญ่ — สองจุดสีจะได้แค่สีเหลืองแบน

**ความลึกมาจากเงาซ้อนชั้นและเกรน** ไม่ใช่เงาเรืองแสง เงาเรืองแสงสีทองเป็นภาษาของเกม
ไม่ใช่ของงานประณีต เงาซ้อนสี่ชั้นระยะเบลอเพิ่มทีละเท่าตัว บวกเส้นสว่าง**โทนอุ่น** 1px
ด้านบน (ขาวเย็นข้างทองจะดูราคาถูกทันที) และเกรน 4% ทับทั้งหน้าเพื่อไม่ให้พื้นกว้างขึ้นแถบ

**อักษรไทยไม่ใช่อักษรละติน** ช่องไฟติดลบและระยะบรรทัดต่ำกว่า 1.2 ที่ใช้กับหัวเรื่องละติน
จะตัดสระบน-ล่างและวรรณยุกต์ หัวเรื่องไทยจึงใช้ช่องไฟปกติและระยะบรรทัดไม่ต่ำกว่า 1.22
ส่วนอักษรจีนขนาดใหญ่ต้องการช่องไฟ**บวก** (.08em ขึ้นไป) ไม่ใช่ลบ

**ไหวติงเท่าที่จำเป็น** แสงกวาดบนตัวอักษรทองรอบละ 9 วินาทีแล้วนิ่งยาว
(วิ่งรัวต่อเนื่องคือสัญญาณของความถูก) · การ์ดยกขึ้น 4px ไม่ใช่ขยายขนาด ·
ทุกอย่างเคารพ `prefers-reduced-motion` และการค่อย ๆ ปรากฏใช้ `animation-timeline: view()`
ซึ่งทำงานบน compositor ไม่ใช้ JavaScript เบราว์เซอร์ที่ยังไม่รองรับจะแสดงเนื้อหาทันที

## หลักการที่ยึดไว้

**ยึดชื่อจีนเป็นหลัก** ชื่อไทยของ ๓๓ ปางในไทยมีสองสาย — สายแปลความ (“ปางกิ่งหลิว”)
ที่ใช้ตามป้ายศาลเจ้า และสายแปลศัพท์ธรรม (“นีลกัณฐอวโลกิเตศวร”) ที่เชื่อกลับไปหาคัมภีร์ได้
ระบบเก็บทั้ง `name_th` (สายแปลความ) `name_th_scholarly` (สายแปลศัพท์ธรรม)
และ `name_th_shrine` (ชื่อที่ป้ายในตำหนักใช้จริง) ถ้ามีชื่อของตำหนัก เว็บจะแสดงชื่อนั้น
ที่เหลือไปอยู่ท้ายหน้าเป็น “ชื่ออื่นที่พบ” เพื่อให้ค้นด้วยชื่อสายไหนก็เจอ
รูปอักษรจีนทางเลือก (เช่น 巖戶／岩戶) เก็บใน `name_zh_variants`

**แยกสามระดับของข้อมูล** ตามที่ต้นฉบับหนังสือกำหนดไว้ — *หลักฐาน* (ตรวจย้อนได้จากพระสูตร
จารึก ทะเบียนวัตถุ) · *คติและตำนาน* (สิ่งที่ผู้ศรัทธาเล่าสืบกันมา) · *คำอธิบายเชิงตีความ*
(ความหมายที่ผู้เรียบเรียงเสนอ) หน้าบทเต็มแสดงคำอธิบายระดับนี้ไว้บนสุดทุกหน้า
และ “แก่นของปาง” มีป้ายกำกับเสมอว่าเป็นการตีความ ไม่ใช่ถ้อยคำจากพระสูตร

**หมวดพรเป็นธรรมเนียมของตำหนัก ไม่ใช่ข้อกำหนดในพระสูตร** ต้นฉบับระบุว่ายังไม่มีใครรวบรวมว่า
“ธรรมเนียมการไหว้เฉพาะปาง” มีอยู่ที่ศาลเจ้าใดบ้าง ทุกหน้าที่แสดงหมวดพรจึงมีคำกำกับไว้
และธง `content.wishes_verified` ใน `site.json` ยังเป็น `false` จนกว่าตำหนักจะยืนยัน

**เนื้อหาที่ไม่มีแหล่งอ้างอิง จะไม่เผยแพร่** ปางที่ทั้ง `verified_by` และ `source_doc` ว่าง
จะยังมีหน้าอยู่ (ป้าย QR ที่พิมพ์ไปแล้วต้องใช้ได้) แต่แสดงเฉพาะชื่อ ภาพ
ลักษณะเด่น และหมวดพร พร้อมป้ายแจ้ง และไม่ส่งให้ Google เก็บดัชนี
เพราะเว็บนี้จะกลายเป็นแหล่งอ้างอิงของคนอื่นต่อไป

**องค์ที่ยังไม่มา ไม่ซ่อน** ปางที่ `enshrined: false` ยังอยู่ในตาราง
แสดงเป็น “กำลังอัญเชิญ” โดยเลขลำดับ ๑–๓๓ ยังครบ

**QR ชี้ที่ `slug` ไม่ใช่เลขลำดับ** ถ้าตำหนักเปลี่ยนลำดับปางภายหลัง
ป้ายที่พิมพ์ไปแล้วยังใช้ได้ — แต่ **ห้ามเปลี่ยน `slug` หลังส่งพิมพ์ป้ายแล้ว**

**สองภาษา ไทยเป็นหลัก จีนเป็นส่วนเสริม** ไทยอยู่ที่ราก จีนอยู่ใต้ `/zh`
ฝั่งจีนแปลเฉพาะหน้าที่ผู้มาเยือนชาวจีนต้องใช้จริง — ข้อมูลตำหนัก ๓๓ ปาง วิธีไหว้
เวลาเปิดปิด การเดินทาง และปฏิทิน ส่วนบทความฉบับเต็ม ข่าว และหน้าหมวดพร
ยังเป็นภาษาไทยเท่านั้น **หน้าที่ยังไม่มีคู่แปลจะไม่หลอกผู้อ่านว่ามี**
ปุ่มสลับภาษายังกดได้แต่พาไปหน้าแรกของอีกภาษา พร้อมบอกตรง ๆ ว่าหน้านี้ยังไม่มีฉบับแปล
รายการหน้าที่แปลแล้วอยู่ที่ `TRANSLATED_ROUTES` ใน `src/i18n/index.ts`
และใช้ตัวเดียวกันนี้สร้าง `hreflang` ให้ Google

**หน้าแรกสลับเองตามวัน** ก่อน ๒๕ ต.ค. ฮีโร่หน้าแรกคือพิธีเปิด
หลังวันงานสลับกลับเป็นหน้าปกติ ทำได้เพราะ CI สร้างเว็บใหม่ทุกวัน
ไม่ต้องมีใครไปกดอะไร

**ใช้งานได้โดยไม่มี JavaScript** ตัวกรองพรบนหน้ารวมเป็นลิงก์ไป `/wish/{หมวด}`
เมื่อไม่มี JS และกรองในหน้าเมื่อมี JS · แถบเวลาเปิดปิดแสดงทั้งสัปดาห์
เมื่อไม่มี JS และเปลี่ยนเป็น “วันนี้เปิด…” เมื่อมี
