# วิดีโอต้นฉบับ

วางไฟล์วิดีโอความละเอียดเต็มไว้ที่นี่ แล้วรัน `npm run video`

ต้องมี ffmpeg ในเครื่องก่อน — วิธีไหนก็ได้

```sh
npm install --no-save ffmpeg-static     # ง่ายที่สุด ไม่ค้างอยู่ในโครงการ
brew install ffmpeg                     # หรือ apt install ffmpeg
FFMPEG_PATH=/path/to/ffmpeg npm run video
```

ffmpeg ไม่ได้อยู่ใน dependencies โดยตั้งใจ เพราะไฟล์ไบนารีเกือบ ๘๐ MB
และเครื่องที่ deploy ไม่เคยได้ใช้ — ไฟล์ที่แปลงแล้ว commit ไว้ในโครงการอยู่แล้ว

สคริปต์จะสร้างไฟล์สำหรับเว็บลง `public/video/` ให้สองไฟล์ต่อหนึ่งคลิป

| ไฟล์ที่ได้ | คืออะไร |
|---|---|
| `<ชื่อ>.mp4` | ไฟล์ที่เว็บใช้ — บีบแล้วและย้ายดัชนีไปหน้าไฟล์ |
| `<ชื่อ>-poster.jpg` | ภาพปก ตัดจากเฟรมแรกของคลิปเอง |

แล้วอัปเดต `video` ใน `src/data/site.json` ตามค่าที่สคริปต์พิมพ์ออกมา
(`file`, `bytes`, `width`, `height`)

## สคริปต์ทำอะไรให้บ้าง

1. **ย้ายดัชนีไปหน้าไฟล์ (faststart)** — ไฟล์จากกล้องและจากเครื่องมือ AI
   มักเก็บตารางดัชนีไว้ท้ายไฟล์ ทำให้เบราว์เซอร์ต้องโหลดครบทั้งไฟล์ก่อนถึงจะเล่นได้
   และเลื่อนดูไม่ได้เลย คนที่เปิดจาก 4G จะเห็นจอนิ่ง ๆ แล้วนึกว่าเว็บเสีย
2. **บีบใหม่** ด้วย CRF และลดจุดรบกวนเบา ๆ ก่อน
   คลิปที่สร้างด้วย AI มีจุดรบกวนละเอียดทั่วภาพซึ่งกินบิตมากโดยที่ตาแทบไม่เห็น
3. **ตัดแทร็กเสียงที่เงียบทิ้ง** — ถ้าความดังเฉลี่ยต่ำกว่า −40 dB
   ถือว่าไม่ใช่เสียงบรรยากาศ ถ้าคลิปมีเสียงจริงสคริปต์จะเก็บไว้ให้เอง

## ข้อควรรู้เรื่องสัดส่วน

คลิปปัจจุบันเป็นแนวตั้ง 3:4 (768×1024) เว็บจึงวางกรอบเป็น 3:4 ตามไฟล์
ถ้าเปลี่ยนไปใช้คลิปสัดส่วนอื่น ต้องแก้ `width`/`height` ใน `site.json` ด้วย
ไม่งั้นจะเห็นแถบดำข้างคลิป

## วิดีโอแนะนำตัวฉบับยาว

คลิปสั้นวนซ้ำใช้เป็นภาพเคลื่อนไหวประกอบได้ แต่ไม่ใช่วิดีโอแนะนำตำหนัก
วิดีโอยาว ๔๕–๖๐ วินาที **ไม่ควรโฮสต์เอง** เพราะไฟล์จะหนักหลายสิบเมกะไบต์
ให้ขึ้นยูทูบแล้วใส่รหัสคลิปที่ `video.youtube` ใน `site.json`
เว็บจะขึ้นให้เองแบบฝังเบา — โชว์ภาพปกก่อน โหลดตัวเล่นเมื่อกดเท่านั้น
