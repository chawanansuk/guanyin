# ภาพต้นฉบับจากช่างภาพ

วางไฟล์ภาพความละเอียดสูงไว้ที่นี่ แล้วรัน `npm run images`
สคริปต์จะย่อเป็น WebP ๓ ขนาด (480 / 960 / 1600 px) ลง `public/images/pang/`
และอัปเดต `src/data/photos.json` ให้เอง

ไฟล์ในโฟลเดอร์นี้ **ไม่ถูก commit เข้า git** (ไฟล์ใหญ่เกินไป)
ให้เก็บต้นฉบับไว้ใน Google Drive ของตำหนัก แล้ว sync ลงเครื่องก่อนรันสคริปต์

## ชื่อไฟล์

| ไฟล์ | ใช้ที่ไหน |
|---|---|
| `pang-01.jpg` … `pang-33.jpg` | ภาพองค์เต็ม 3:4 แนวตั้ง — หน้ารวมและหน้าปาง |
| `pang-01-detail.jpg` … | ภาพรายละเอียด พระหัตถ์/สิ่งที่ถือ |
| `shrine-main.jpg` | องค์ประธาน — หน้าแรก |
| `shrine-exterior.jpg` | หน้าอาคาร |
| `shrine-wide-1.jpg` … | มุมกว้างภายในตำหนัก |

เลขต้องตรงกับลำดับปางที่ตำหนักยืนยัน ถ้าลำดับเปลี่ยนให้เปลี่ยนชื่อไฟล์ตาม
ระบบจับคู่ภาพกับข้อมูลด้วยชื่อไฟล์ ไม่ใช่ลำดับในโฟลเดอร์

## สเปกการถ่าย (ย่อ)

- 3:4 แนวตั้ง ด้านยาว ≥ 3000px ถ่าย RAW
- ขาตั้งสูง 1.2 ม. · เลนส์เทียบเท่า 50mm · f/5.6 · ISO ≤ 400
- ไฟต่อเนื่อง ๒ ดวง 45° ซ้าย–ขวา · WB ล็อก 5000K · ปิดไฟนีออนในตำหนัก
- พื้นหลังผ้า/บอร์ดสีเทากลาง 18% ตั้งหลังองค์ทุกครั้ง
- องค์อยู่กลางเฟรม ฐานเห็นครบ เหลือขอบบน 10% ล่าง 8%
- **ถ่ายทั้ง ๓๓ องค์ในวันเดียว** — ถ่ายหลายวันแสงจะไม่เหมือนกันและเรียงเป็นตารางแล้วจะดูรก
